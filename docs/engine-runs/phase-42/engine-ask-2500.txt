engine-ask.mjs: the authoring asks (1500 ms, four lines) that chose the lines, then every finding re-checked at 2500 ms, in the order they were run.
Conditions: 16 logical processors, CPU load sampled at 18-21% before each run (the idle Vite dev servers of
other projects and this session's own shells; no javac, cargo, rustc or tauri process), no build, no test run
beside any 2500 ms run, one engine process at a time, every run in this phase sequential. Four hung python
shells from this session's own scratch work were found spinning at 40% before the first pass and ended before
it began; no engine run of this phase overlapped them.
Evaluations are from White's point of view: positive favours White, so a Black move that gives something
away makes the number go UP. The course's own bar (chip 42.4): a flagged Black move is kept if the position
after it is no worse than about +0.6 for White and it is the theory move, judged by its cost against the
engine's best.
